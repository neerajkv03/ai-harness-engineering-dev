# Changelog format

Use these headings, in this order. Omit a heading that has no entries.

- **Added** for new features
- **Changed** for behavior changes
- **Fixed** for bug fixes
- **Removed** for removed features

Rules:
- One line per change, in the imperative: "Add pagination to GET /users".
- End each line with the short commit hash or PR number in parentheses.
- Put breaking changes first and start the line with "BREAKING:".
